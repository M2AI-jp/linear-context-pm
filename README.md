# linear-context-pm

## これは何

`linear-context-pm` は、Linear を中心に PM 文脈を整理するための個人用 Codex skill です。ユーザー原文、SSoT、決定、受け入れ済みの結果を分け、次の AI/Codex 作業に渡す入力コンテキスト `X` を汚さないための小さな型です。

## なぜ作ったか

きっかけは、ユーザーが共有してくれた本『[プロフェッショナルAI駆動開発](https://www.amazon.co.jp/dp/4297157888)』と、自分のプロジェクトでコンテキスト管理を失敗した経験です。入力 `X` が混ざると AI/Codex の出力 `Y` も濁る。逆に、`X` をきれいに保てば `Y` は改善しやすい。その学びを Linear 前提の PM ループとして残しました。

## 使い方

このディレクトリを Codex の skills 配下に置くか、必要な内容だけ自分の skill に取り込んでください。Codex で `$linear-context-pm` を呼び、Linear 中心の PM コンテキスト設計・監査・オンボーディングに使います。プロジェクト事情に合わせて自由に削ってください。
