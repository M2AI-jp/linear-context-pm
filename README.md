# linear-context-pm

Linear を、AI/Codex に作業を任せるための「PM コンテキスト置き場」として使う個人用 Codex skill です。

## 背景

『[プロフェッショナルAI駆動開発〜確率論から決定論へ AIの揺らぎを制御する開発フレームワーク〜](https://www.amazon.co.jp/dp/4297157888)』の `Y = F(X)` という考え方に影響を受けて作りました。

ここでは、`X` を AI に渡す入力コンテキスト、`F` をモデルと実行のさせ方、`Y` を出力と受け入れ結果として捉えています。AI の出力は揺れるので、モデルの賢さだけに期待するより、まず `X` をきれいに保つことが実務では効きます。

自分の開発でも、古い判断、過去の失敗、未検証のテスト、GitHub に残らないブラウザや SaaS 上の作業が混ざると、Codex がそれを正しい前提として増幅してしまうことがありました。この skill は、その反省から作った小さな入力整理の型です。

## 何をするか

- 現在の目的、過去事例、非目標、権限境界を分ける
- Linear にはコード外の PM 判断だけを置く
- Git、CI、外部サービスの生ログはそれぞれの場所を正とする
- E2E、テストレビュー、受け入れ済みの結果だけを次の `X` に入れる
- Issue、PR、レビューを必要以上に増やさない

## 使い方

Codex の skills 配下にこのディレクトリを置き、Linear 中心に PM コンテキストを設計・監査したいときに `$linear-context-pm` を呼び出してください。

自分のプロジェクト事情に合わせて、必要な部分だけ使ってください。
